# KLIC FotoMarker — Android updates

Deze openbare repository bevat straks alleen de **officiële APK-updates** voor KLIC FotoMarker. Je hebt **geen GitHub-account** nodig om de app bij te werken.

## Downloaden op je Samsung

1. Open [de nieuwste release](https://github.com/jorvsh1985-netizen/KLIC-FotoMarker-Updates/releases/latest).
2. Download **KLIC-FotoMarker.apk** onder **Assets**.
3. Open de download. Android vraagt om bevestiging voor het installeren.
4. Installeer **over de bestaande app** om lokale foto's, markeringen en gekoppelde KLIC-kaarten te behouden.

## Updates vanuit de app

Vanaf de vaste releaseversie controleert **Controleer op updates** deze openbare releasepagina. De app kan een nieuwere APK downloaden en de Android-installatie starten. Android vraagt altijd om jouw goedkeuring.

> **Belangrijk:** een update werkt alleen als zowel de bestaande als nieuwe APK dezelfde pakketnaam en digitale ondertekeningssleutel gebruiken. Oude v4/v5/v6-testversies hebben andere pakketnamen. Maak daarvan eerst een back-up en zet die éénmalig over naar de vaste releaseversie.

## Privacy

In deze repository horen **uitsluitend installatiebestanden en update-informatie**. Plaats hier geen KLIC-kaarten, foto's van kabelbedden, locatiegegevens, back-ups, privébroncode of ondertekeningssleutels.

## Huidige status

De eerste officieel ondertekende openbare release moet nog worden gepubliceerd. Tot dan blijft de download via **Releases** leeg. Installeer niet willekeurige APK's van derden.
